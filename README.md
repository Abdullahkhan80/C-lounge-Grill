# C Lounge & Grill — Bronx, New York

A modern, production-quality, responsive website for **C Lounge & Grill**, located at 1735 E 172nd St, Bronx, NY 10472.

Designed with an upscale New York lounge aesthetic: Deep Charcoal (`#101010`), Dark Graphite (`#1B1B1B`), Champagne Gold (`#C9A56A`), and Warm Ivory (`#F5F0E8`), with typography in `Cormorant Garamond` and `Inter`.

## Key Features & Pages

- **Home (`/`)**: Cinematic hero with micro badges, story preview, 3 core experiences (Dining, Cocktails, Lounge), menu preview, ambience storytelling, event previews, and location map.
- **About Us (`/about`)**: Hospitality story, culinary philosophy, and Bronx neighborhood roots.
- **Our Menu (`/menu`)**: Interactive category filtering (Appetizers, Grill Favorites, Main Courses, Cocktails, Desserts), search capability, and dietary tags.
- **Atmosphere Gallery (`/gallery`)**: Filterable masonry grid with interactive full-screen image lightbox modal.
- **Events (`/events`)**: Upcoming lounge sessions preview and private celebration inquiry form.
- **Reservations (`/reservations`)**: Modern table booking request experience with client- and server-side validation.
- **Contact (`/contact`)**: Verified address, phone, directions, operating schedule, and validated contact form.
- **API Endpoints**: `/api/reservations` and `/api/contact` with validation and integration hooks.
- **SEO Ready**: Dynamic `sitemap.xml`, `robots.txt`, and LocalBusiness / Restaurant JSON-LD schema.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## Tech Stack

- **Framework**: Next.js 16 (App Router) & React 19
- **Language**: TypeScript
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Animations**: Framer Motion
